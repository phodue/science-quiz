# 중2 과학 퀴즈

학기별 과학 퀴즈 사이트입니다. 문제는 `data/` 폴더의 Markdown 파일에 들어 있어서, md 파일만 고치면 사이트에 바로 반영됩니다.

## 폴더 구조

```
index.html            퀴즈 화면 (수정할 일 거의 없음)
data/semesters.json   학기 목록 (위에 있는 학기가 처음에 열림)
data/m2-2-mid.md      중2-2학기-중간 (Ⅴ 식물과 에너지 ~ Ⅵ 동물과 에너지, 150문제)
```

## 문제 쓰는 법

```markdown
## Ⅵ-1. 소화계              ← 단원

### 위액 속에 들어 있는 단백질 소화효소는?   ← 문제
- [x] 펩신                     ← 정답 (꼭 1개)
- [ ] 트립신 — 이자액          ← 오답 (— 뒤는 보기 설명)
- [ ] 아밀레이스
- [ ] 라이페이스
> 단백질은 위에서 펩신에 의해 처음 분해된다. (교과서 p.211 · PDF 105쪽)   ← 해설
```

- 문제를 지우려면 `### 문제`부터 `> 해설`까지 통째로 지웁니다.
- 보기 순서는 퀴즈에서 자동으로 섞입니다.

## 새 학기 추가하기

1. `data/` 폴더에 새 md 파일을 만듭니다 (예: `data/m2-2-final.md`, 첫 줄은 `# 중2-2학기-기말`).
2. `data/semesters.json`에 한 줄을 추가합니다.
   ```json
   { "id": "m2-2-final", "title": "중2-2학기-기말", "file": "data/m2-2-final.md" }
   ```

## 참고

- 사이트가 md 파일을 불러오는 방식이라, `index.html`을 컴퓨터에서 더블클릭해 열면(file://) 문제가 보이지 않습니다. GitHub Pages 주소로 열거나, 폴더에서 `python -m http.server`를 실행한 뒤 http://localhost:8000 으로 열어 주세요.
- 오답노트는 학기별로 따로 저장됩니다 (브라우저에 저장).
