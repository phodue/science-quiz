## Ⅴ-1. 광합성

- [x] 광합성

> 식물의 광합성은 빛에너지를 이용하여 양분을 만드는 과정이다. (p.178)

> 엽록체에서 광합성이 일어나 녹말이 만들어졌기 때문에 청람색으로 변한다. (p.178~179)

### 검정말 잎의 엽록체가 아이오딘-아이오딘화 칼륨 용액에 의해 청람색으로 변했다. 이를 통해 알 수 있는 엽록체 속 물질은?
- [x] 녹말
- [ ] 산소 — 기체이며 아이오딘 반응과 관계없음
- [ ] 단백질 — 뷰렛 용액으로 검출
- [ ] 이산화 탄소 — 광합성에 쓰이는 기체
> 아이오딘-아이오딘화 칼륨 용액은 녹말과 반응해 연한 갈색에서 청람색으로 변한다. (p.178)

### 식물 세포에서 광합성이 일어나는 세포소기관은?
- [x] 엽록체
- [ ] 마이토콘드리아 — 호흡이 일어나는 세포소기관

- [ ] 세포벽 — 식물 세포의 모양을 유지하는 단단한 벽
> 광합성은 식물 세포의 엽록체에서 일어난다. 엽록체는 초록색을 띠는 작은 알갱이 모양이다. (p.179)

### 엽록체 속에 들어 있으며, 광합성에 필요한 빛에너지를 흡수하는 초록색 색소는?
- [x] 엽록소

- [ ] 녹말 — 광합성으로 만들어져 저장되는 양분
- [ ] 공변세포 — 기공을 둘러싼 세포
> 엽록체에는 엽록소라는 초록색 색소가 있는데, 엽록소는 광합성에 필요한 빛에너지를 흡수한다. (p.179)

### 광합성 과정에 필요한 물질 두 가지를 옳게 짝 지은 것은?
- [x] 물, 이산화 탄소
- [ ] 포도당, 산소 — 광합성으로 만들어지는 물질
- [ ] 물, 산소 — 산소는 광합성 결과 생성됨
- [ ] 이산화 탄소, 포도당 — 포도당은 광합성 결과 생성됨
> 식물은 엽록체에서 빛에너지를 이용해 이산화 탄소와 물로부터 포도당과 산소를 만든다. (p.179)

- [x] 뿌리

### 식물이 광합성에 필요한 이산화 탄소를 흡수하는 통로는?
- [x] 잎의 기공
- [ ] 뿌리털 — 물을 흡수하는 곳
- [ ] 체관 — 양분이 이동하는 통로
- [ ] 물관 — 물이 이동하는 통로

### 기공에 대한 설명으로 옳지 않은 것은?
- [x] 주로 잎의 앞면에 분포하며 물을 흡수한다.
- [ ] 공기 중의 이산화 탄소를 흡수한다. — 맞는 내용
- [ ] 광합성으로 만든 산소를 방출한다. — 맞는 내용
- [ ] 증산되는 물의 양을 조절한다. — 맞는 내용
> 기공은 주로 잎의 뒷면에 분포하며, 물은 뿌리로 흡수한다. (p.179)

### 광합성으로 만들어진 포도당은 엽록체에 어떤 형태로 저장되는가?

### 밀폐 용기에 시금칫잎을 넣고 빛을 비추며 기체 농도를 측정했다. 시간이 지남에 따른 변화로 옳은 것은?

- [x] 바람의 방향

## Ⅴ-2. 식물의 호흡과 광합성산물

### 식물이 광합성으로 만들어진 양분과 산소를 이용하여 생명활동에 필요한 에너지를 얻는 과정은?
- [x] 호흡
- [ ] 광합성 — 양분을 만드는 과정
- [ ] 증산 작용 — 기공으로 물이 빠져나가는 현상
- [ ] 여과 — 콩팥에서 일어나는 오줌 생성 과정
> 식물도 생장하고 꽃을 피워 열매를 맺으려면 에너지가 필요하며, 이 에너지를 호흡으로 얻는다. (p.190)

### 식물의 호흡을 나타낸 식으로 옳은 것은?
- [x] 포도당 + 산소 → 이산화 탄소 + 물 + 에너지
- [ ] 이산화 탄소 + 물 → 포도당 + 산소 — 광합성
- [ ] 포도당 + 이산화 탄소 → 산소 + 물 + 에너지
- [ ] 산소 + 물 → 포도당 + 이산화 탄소
> 호흡은 포도당과 산소를 이용해 이산화 탄소와 물을 만들고 에너지를 얻는 과정이다. (p.190, 194)

### 식물에서 호흡이 일어나는 시기로 옳은 것은?
- [x] 낮과 밤 구분 없이 항상 일어난다.
- [ ] 낮에만 일어난다.
- [ ] 밤에만 일어난다. — 밤에는 호흡'만' 일어날 뿐, 낮에도 호흡함
- [ ] 빛이 강할 때만 일어난다. — 광합성의 특징
> 광합성은 빛이 있을 때만 일어나고, 호흡은 낮과 밤의 구분 없이 항상 일어난다. (p.190)

### 낮에 식물 안에서 광합성과 호흡 사이에 일어나는 일로 옳은 것은?
- [x] 광합성으로 만든 산소가 호흡에 이용되고, 호흡으로 만든 이산화 탄소가 광합성에 이용된다.

## Ⅵ-1. 소화계

### 음식물이 지나가는 소화관의 순서로 옳은 것은?

- [ ] 입 → 식도 → 간 → 위 → 작은창자 → 항문 — 간은 음식물이 지나가지 않음

- [ ] 배설 — 노폐물을 몸 밖으로 내보내는 것
- [ ] 순환 — 혈액이 온몸을 도는 것
> 녹말, 단백질, 지방은 크기가 커서 세포로 바로 흡수될 수 없으므로 소화가 필요하다. (p.208)

### 밥을 오래 씹으면 단맛이 나는 까닭은?
- [x] 침 속의 아밀레이스가 녹말을 엿당으로 분해하기 때문이다.

- [ ] 쓸개즙이 녹말을 분해하기 때문이다.
- [ ] 펩신이 단백질을 분해하기 때문이다.
> 녹말은 단맛이 거의 없지만, 아밀레이스에 의해 분해된 엿당은 단맛이 난다. (p.208, 210)

- [ ] 이자 — 이자액 분비

### 주머니 모양이며 소화액인 위액을 분비하여 음식물을 소화하는 기관은?
- [x] 위
- [ ] 작은창자 — 길고 꼬불꼬불한 관 모양
- [ ] 쓸개 — 쓸개즙 저장
- [ ] 방광 — 오줌을 모아 두는 곳 (배설계)

- [ ] 이자 — 이자액 생성

- [x] 쓸개
- [ ] 간 — 쓸개즙을 만드는 곳
- [ ] 이자 — 이자액을 만드는 곳
- [ ] 방광 — 오줌을 저장하는 곳

- [ ] 이산화 탄소 – 순환계, 요소 – 소화계
> 이산화 탄소는 호흡계, 요소와 같은 노폐물은 배설계를 통해 몸 밖으로 나간다. (p.231)

### 기관계와 그 역할을 옳게 짝 지은 것은?
- [x] 순환계 – 영양소와 산소를 온몸의 세포로 운반한다.
